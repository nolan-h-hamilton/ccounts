# `ccounts`

* Utilities for counting in bulk and single-cell seq data.
* Inlined genome assembly resources for human, mouse, rat, fruit flies, yeast, etc.
* Fast C backend with vendored HTSLIB and cython wrappers 

Many of these resources were formerly packaged with `Consenrich` but have outgrown it and are easier to maintain as a separate package now.

Documentation is a work-in-progress but the code is organized to be 'self-documenting' for most purposes. Feel free to open an issue if anything is unclear. PRs welcome.
